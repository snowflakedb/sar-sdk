# Security

This pre-release SDK has no production-support or security-certification claim.
Do not post credential values, SQL results, or reproduction material containing
customer data in issues or pull requests.

## Reporting a vulnerability

Please refer to the Snowflake [HackerOne program](https://hackerone.com/snowflake?type=team)
for our security policies and for reporting any security vulnerabilities. Don't report
vulnerabilities in GitHub issues. For other security-related questions and concerns, contact the
Snowflake security team at security@snowflake.com.

## Trust boundaries

Each language's trust boundaries, error-handling guidance, and limitations are documented with its
SDK:

- [Node.js](nodejs/SECURITY.md)
